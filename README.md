# WebAv_ExamReview

Guía de estudio interactiva para el examen de **Aplicaciones Web Avanzadas** (ISWD813, EPN · FIS), capítulos 1 y 2.

Es una sola página estática (`index.html`), sin dependencias de compilación, lista para desplegar en Vercel o GitHub Pages.

## Contenido

- **Plan de estudio** por bloques, con avance guardado en el navegador.
- **Preguntas del profe**: las confirmadas en clase (docker de SQL Server, RHEL, bcp, ADO.NET, CLR, Entity Framework, ad hoc, WebSocket) y preguntas relacionadas.
- **Parte práctica**: plantillas para el chat WebSocket, Socket.IO, ASP clásico y Web Forms.
- **9 temas** de clase (IIS, .NET, Agentes IA, ASP clásico, apps modernas, monolíticos, AJAX, polling, WSS/TLS/JWT).
- **7 laboratorios** resumidos (SQL Server en Docker, PoliMusic ASP, monolito .NET 2.0, N-Tier .NET 4.8, chat WebSocket, WSS + JWT, Socket.IO).
- **Flashcards** de siglas, **quiz** autocalificado y **preguntas abiertas** con respuesta modelo.

## Estructura

```
index.html                 página de estudio
material/clases/           PDFs de las clases
material/laboratorios/     PDFs y documento de los laboratorios
```

## Ejecutar en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```
